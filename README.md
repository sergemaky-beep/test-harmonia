# Harmonia Syndic - Next.js 14 Project

Un site web moderne pour Harmonia Syndic, une société de gestion de copropriété française.

## Stack Technique

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Font**: Inter (Google Fonts)

## Couleurs de la Marque

- Primaire: `#1B4F72`
- Secondaire: `#2E86C1`
- Accent: `#F39C12`
- Clair: `#EBF5FB`

## Structure du Projet

```
src/
├── app/
│   ├── layout.tsx          # Layout racine
│   ├── page.tsx            # Page d'accueil
│   └── globals.css         # Styles globaux
└── components/
    ├── Header.tsx          # En-tête du site
    ├── Footer.tsx          # Pied de page
    ├── StatsBar.tsx        # Barre de statistiques
    ├── FeatureCard.tsx     # Carte de service
    ├── TestimonialCard.tsx # Carte de témoignage
    ├── CTASection.tsx      # Section d'appel à l'action
    └── GuideCard.tsx       # Carte de guide
```

## Démarrage

### Installation

```bash
npm install
```

### Développement

```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

### Build pour la production

```bash
npm run build
npm start
```
